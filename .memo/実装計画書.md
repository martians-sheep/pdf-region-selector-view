# 実装計画書: PDF.js（react-pdf想定）上で矩形ドラッグ選択し、PDFページ座標を取得する

## 0. 目的 / スコープ
### 目的
- PDFを表示し、ページ上でユーザーがドラッグして矩形範囲を作成できるUIを実装する
- 作成した矩形の座標を **PDFページ座標（PDF points）** として取得・保持・出力できるようにする
- **ズーム倍率変更に対応**し、座標取得が破綻しないようにする（回転は非対応）

### スコープ外
- バックエンドでのテキスト抽出
- 複雑な注釈/マルチページ跨ぎ/回転/傾き補正
- 永続化（DB保存）は任意（ローカルstate保持とJSON出力までを必須とする）

---

## 1. 技術スタック / 前提
- React
- PDF表示: `react-pdf`（内部で pdf.js を利用）
- 対象: 1ページ表示（まずは単ページで完成させ、必要なら複数ページへ拡張）
- 回転なし（rotation=0）
- ズーム対応（scale state）

---

## 2. 成果物（Definition of Done）
- PDFを表示できる（任意のPDF URL または file upload）
- ページ上でドラッグすると矩形が表示される（選択中プレビュー）
- ドラッグ終了で矩形が確定し、以下のデータが取得できる:
  - pageNumber
  - x, y, width, height（PDFページ座標: points）
  - pageWidth, pageHeight（PDFページ座標: points）
- ズーム（scale変更）後も、確定済み矩形が同じ位置に再描画される（PDF座標で保持し、表示時にDOMへ変換する）
- 取得した矩形一覧をJSONとして画面に表示（コピー可能）
- 既存矩形の削除（最低限のUXとして1件削除・全削除どちらかは実装）

---

## 3. 座標系の設計（最重要）
### 3.1 方針
- ユーザー操作は **DOM/CSS px**（overlay上のローカル座標）で取得
- 保存する座標は **PDFページ座標（points）**
- 変換は必ず `viewport` を経由する

### 3.2 取り決め
- PDF座標の `x,y,width,height` は **PDF.jsのconvertToPdfPoint系の結果**に準拠（原点やy向きはpdf.jsの仕様に合わせる）
  - ※バックエンドはスコープ外のため、今回は「pdf.js基準のPDF座標」を正とする
- 回転は0固定、ズームは `scale` によってのみ変化

## 4. UI仕様
### 4.1 画面構成
- 上部ツールバー
  - Zoom Out / Zoom In（scale変更）
  -（任意）Reset Zoom
  -（任意）Clear Selections
- PDF表示エリア
  - `react-pdf` の `<Page />` を表示
  - Page領域と完全一致する overlay を absolute で被せる
- 選択結果
  - 矩形一覧（ページ番号と座標）
  - JSON出力（textarea / pre）
  - Copyボタン（任意）

### 4.2 操作仕様
- overlay上の pointer drag で矩形作成
- ドラッグ中は矩形のプレビュー表示
- pointer up で確定（最小サイズ閾値あり: 例 3px 未満は無効）
- 既存矩形は表示され続ける（ズームでも追従）
- 矩形はクリックで選択状態にできる（任意）
- 削除（選択削除または一覧の削除ボタン）

## 5. 実装タスク一覧（LLMに実装させる単位）

### Task A: PDF Viewer 基盤（react-pdf）

- [ ] `<Page />` の `onLoadSuccess` で `PDFPageProxy` を取得して state に保持

#### 受け入れ条件

### Task B: overlay基盤（ページ領域一致）
- [ ] Pageを `position: relative` なwrapperで包む
- [ ] overlayを `position:absolute; inset:0; touch-action:none;` で配置
- [ ] overlayのサイズがPageの表示領域と一致していることを確認（余白/padding/border無し）

#### 受け入れ条件
- overlay上でpointerイベントが取得できる
- overlayがPageからズレない

---

### Task C: ドラッグ選択（DOM座標で矩形生成）
- [ ] `usePointerDrag`（または同等）を実装
  - pointerdown: 開始点取得、pointer capture
  - pointermove: 現在点更新
  - pointerup/cancel: 確定 or キャンセル
- [ ] overlayローカル座標（CSS px）で `DomRect {left, top, width, height}` を生成
- [ ] ドラッグ中の矩形を表示（border + 透明塗り）

#### 受け入れ条件
- ドラッグで矩形が追従表示される
- pointerupで確定イベントが発火する

---

### Task D: DOM矩形 → PDF矩形変換（viewport利用）
- [ ] `viewport` を `pageProxy.getViewport({ scale })` で取得（useMemo）
- [ ] `viewport.convertToPdfPoint(x, y)` を用いて2点変換（左上/右下）
- [ ] min/maxで正規化して `PdfRect {x,y,width,height}` を生成
- [ ] `pageProxy.getViewport({ scale: 1 })` 等で `pageWidth/pageHeight`（PDF points）を取得して保存

#### 受け入れ条件
- 確定時に `PdfRect` が生成される
- PDF座標がズーム倍率に依存しない値として取得できる

---

### Task E: PDF座標を保持し、表示は逆変換で追従（ズーム対応完成）
- [ ] state: `selections: PdfRect[]` を保持
- [ ] 描画時に `PdfRect -> DomRect` へ逆変換
  - `viewport.convertToViewportPoint(...)` で2点を変換しDomRect化
- [ ] ズーム変更時も既存selectionが同じ箇所に再描画される

#### 受け入れ条件
- ズームを変更しても矩形表示が正しい位置に追従する
- 新規作成した矩形も正しく保存される

---

### Task F: 一覧表示 / JSON出力 / 削除
- [ ] selectionsを一覧表示（index、pageNumber、座標）
- [ ] JSON出力（整形済み）を画面に表示
- [ ] 1件削除、または全削除を実装（最低限どちらか）
- [ ] Copyボタン（任意）

#### 受け入れ条件
- selectionsを可視化できる
- JSONをコピーして外部に渡せる
- 削除できる

## 6. データ構造（実装で固定）
```ts
export type PdfSelection = {
  id: string;
  pageNumber: number;

  // PDF points
  x: number;
  y: number;
  width: number;
  height: number;

  pageWidth: number;
  pageHeight: number;

  createdAt: string;
};
````

## 7. エッジケース / 品質要件

* [ ] ドラッグが極小（例: width<3px or height<3px）の場合は無効
* [ ] pointer capture を使い、ドラッグ中にカーソルがoverlay外に出ても追従する
* [ ] スクロールが発生するコンテナの場合、`clientX/clientY` と `getBoundingClientRect()` 基準でズレないこと
* [ ] `touchAction:none` でモバイルのスクロール干渉を抑制
* [ ] 選択範囲がPage外に出た場合はクリップ（0〜幅/高さの範囲に丸める）

---

## 10. 実装時の注意（失敗しやすいポイント）

* overlayがPageと1pxでもズレると座標変換が全部ズレる（padding/border/transform禁止）
* DOM座標をそのまま保存しない（必ずPDF座標へ変換して保存）
* 表示は常に「PDF→DOM」で再計算する（ズームに強くなる）
* 変換には必ず同じ `viewport`（同じscale）を使う
